清影工坊 VideoMatting 1.0.0 — Windows x64 CPU 绿色版

1. 将整个压缩包解压到可写目录，不要直接在压缩包内运行。
2. 双击「一键启动.cmd」，浏览器会自动打开。
3. 选择视频，等待处理，预览并下载结果。
4. 保持启动窗口打开；关闭窗口会停止服务和当前处理。
5. 也可双击「停止服务.cmd」关闭服务。

无需安装 Python、Node.js 或下载模型，无需管理员权限。
建议 Windows 10/11 64 位、32 GB 内存，保留足够磁盘空间。
4K 原分辨率处理对内存和 CPU 要求较高，普通电脑会较慢。
此包内置 CPU 运行库，即使有 NVIDIA 显卡也不会自动启用 CUDA。
视频只在本机处理。程序本身只监听 127.0.0.1，不对局域网开放。
首次使用时，请允许浏览器打开本地页面。未自动打开时访问：
http://127.0.0.1:8765/

不要删除 runtime、models、vendor、server、web 文件夹。
任务与缓存写入本程序的 data 文件夹；网页删除任务会永久清理其处理文件。
上传前的原始视频不会被改动。建议每位用户使用自己的解压目录。
升级前请关闭旧程序，需要保留历史时先备份 data 文件夹。
程序未进行商业代码签名；安全软件可能提示未知发布者，请核对来源及压缩包校验值。
