### 原画质性能优化（2026-10-14）

- 同一首帧的 10 次预热复用图像编码特征，不减少预热次数；实际处理第一帧后立即释放缓存。
- 相似度矩阵使用键维连续存储，加速 top-k 的内存访问；完整记忆、原尺寸、FP32 和原计算公式保持不变。
- 预热检查点不重复写入可精确重算的静态特征，时序状态仍完整保存。真实权重测试覆盖中途恢复，输出逐值一致。
- `007.mp4` 实测：4096×2160、16 帧、24.022 fps、CPU。旧完成记录为 3472 秒，新完整运行 1386.95 秒，耗时约减少 60.1%。这是与历史记录的比较，不是多轮受控平均值，后台负载会影响结果。完整运行包含特征缓存与布局优化；后加的检查点精简另经真实模型恢复测试验收，不计入提速承诺。
- 新旧输入 SHA-256 一致；16 帧共 141,557,760 个 Alpha 像素差异为 0；最终 WebM 通过 libvpx-vp9 解码为 yuva420p 后逐帧 MD5 全部一致。仍沿用原 VP9 CRF 16，并非声称输出编码无损。
- 独立复测：`.venv\Scripts\python.exe tests/benchmark_video.py 视频路径 --baseline data/jobs/旧任务ID`。结果保存在 `data/benchmarks/时间戳`，不覆盖现有任务；这些独立测试文件不属于网页历史任务。

恢复与性能：完整原帧、首帧遮罩及每次预热状态持久化，逐帧每 5 帧保存完整推理状态；异常后最多重做最后 4 帧。全部 Alpha 已完成时只重新合成。服务重启仍需把模型权重重新载入内存，但无需重算已有的识别/预热检查点。旧版失败任务没有时序检查点，只能复用已有原帧和首帧遮罩。PNG 使用低压缩级别加速无损写入（占用磁盘更多），VP9 开启行并行，attention 按查询分块降低临时内存，保持原分辨率、原帧率、FP32 和完整预热；不承诺固定倍速。

CPU、GPU 计算使用率、内存和 CUDA 显存占用率统一以 95% 为保护阈值：达到阈值暂停进入下一推理计算步骤，低于阈值后自动继续。CPU 与 GPU 计算占用通过采样检查，GPU 数据无法获取时不按虚构值阻塞；GPU 采样最多每秒一次，与页面监控共用缓存。不要求固定空闲 GB 预留，也不按视频尺寸估算值设置门槛。显存达到阈值时先释放本进程闲置缓存再检查，避免自身可回收缓存导致无意义等待。CPU 的四个推理工作线程是并行配置，不是百分比硬上限。该检查不是操作系统硬上限，正在运行的计算或单次分配仍可能超过阈值或失败。等待可取消。突发分配失败会保留检查点并标为可恢复中断，不会自动降低画质；无法保证超出设备容量的素材一定完成。预估时间在首个实际处理帧后按近期帧耗时估算，预热显示已用时间，内存等待与合成分别说明。

“历史任务”支持单条删除与清空：确认后永久删除对应任务目录内的上传副本、结果、帧序列、遮罩、检查点和任务记录，释放磁盘空间；上传前的原始视频及已下载到其他位置的文件不受影响。清空还会删除旧版本已隐藏的任务。选中任务被删除后清空预览；还有任务上传、排队或处理时禁止清空。删除无法撤销，文件被占用导致失败时保留任务入口以便重试。

4K 输入上限包含 3840×2160 和 4096×2160（以及等像素量的竖屏），最长 60 秒、最大 250 MB；上传阶段显示独立实时进度条、百分比与传输大小。尺寸校验通过并不保证 CPU/内存足以高效处理整段 4K 视频，当前开发机尚未验收完整 4K 抠像。

中文名称：清影工坊。拖动播放进度时同步显示两侧对应画面；拖动中暂时暂停，原本正在播放时松开后继续。阶段进度只在上传/排队/处理期间显示，逐帧阶段展示实时已处理/总帧数和百分比。Alpha Matte 模式隐藏背景选项。下载命名为 `VideoMatting-格式-12位任务ID.扩展名`，12 位取自内部 UUID 去除连字符后的前 12 位；内部任务与资源链接仍使用完整 UUID。

上传单人物原视频后，自动识别人物、精细视频抠像、导出透明 WebM。左边原视频、右边透明结果，同步播放/暂停/拖动进度，可切换棋盘格、黑底、白底。任务、结果和母版仅保存在本机，不上传云端，不替换 Client 素材。

## 使用

当前开发机已安装环境和模型。双击 `一键启动.cmd`，自动发现并显示本机局域网 IP，浏览器打开 `http://本机局域网IP:8765`；保留 `http://127.0.0.1:8765` 作为本机访问地址。服务监听 `0.0.0.0:8765`，同一局域网工作机可通过启动窗口中的 IP 上传、预览和下载，所有处理均在启动服务的电脑上执行。停止服务可双击 `停止服务.cmd`，该入口只停止启动器登记的本工具进程。

使用显卡电脑处理、工作机操作：在显卡电脑解压并运行「一键启动」，在工作机浏览器输入该窗口显示的局域网地址即可，无需在工作机安装运行环境。若无法访问，在显卡电脑允许 Windows 防火墙专用网络的 Python/TCP 8765 访问，并确认两台电脑网络互通。局域网访问者共用任务、文件和历史；切换网络或 IP 后需重启服务以更新地址。

源码与完整打包版共用三个入口：`一键启动.cmd`、`停止服务.cmd`、`检测系统.cmd`。命令文件内容完全相同，自动选择内置 runtime 或源码 .venv。源码首次启动会检查环境，缺失时自动安装依赖、下载模型并构建网页；该准备逻辑位于 `setup_environment.py`，无需单独运行安装命令。检测系统显示处理器、内存、CUDA 和模型状态；可用 NVIDIA GPU 会执行一次实际运算验证。

每次运行「检测系统」会将窗口输出和错误堆栈追加保存到 `data/system-check.log`，包含 NVIDIA 驱动信息、实际 Python/PyTorch 路径、CUDA 初始化错误和模型状态。CUDA 初始化失败时在独立进程中诊断，记录输出与退出码，即使原生库崩溃也能完成日志保存。日志超过 5 MB 时保留一份上次日志；服务运行日志仍在 `data/server.log`、`data/server-error.log`。GPU 回退到 CPU 时可通过检测日志定位原因，日志仅保存在本机。

保持启动窗口打开；关闭该窗口或按 Ctrl+C 即停止服务及子进程（正在处理的任务会中断）。再次启动若发现服务已运行，会复用现有服务，并提示关闭原启动窗口。启动提示使用中文，详细第三方错误日志位于 `data/server-error.log`。

左侧预览区域支持点击选择和拖放上传，上方“删除素材 / 重新制作”仅清空当前选择，保留磁盘历史。默认循环播放，空格同步暂停/继续；两侧可各自全屏，也可对比全屏。上传、解码、加载、预热、逐帧抠像、合成均显示阶段进度；逐帧开始后动态估算剩余时间，估算包含初始化开销，不能当作准确承诺。

默认透明 WebM：棋盘格、黑白底、绿幕和自定义颜色只改变预览，不改变透明下载。选择自定义背景模式：预览指定颜色，下载写入相同颜色的 H.264 MP4。选择 Alpha Matte：显示并下载黑白遮罩 H.264 MP4（白色保留、黑色移除、灰色半透明）。两种 MP4 均基于原帧/Alpha 母版生成，无需再次抠像；首次切换会等待格式准备。H.264 遇奇数宽高会补到偶数，最多增加一行或一列。播放循环不等于修复首尾动作接缝。

页面与本地处理无需按次付费，但不代表依赖模型具有免费商用许可，见文末许可说明。

新电脑先安装 Python 3.13、Node.js 与 pnpm 10.18，再运行 `一键启动.cmd`，缺失的环境会自动准备。首次需要联网下载依赖和模型，之后在权重齐备时可离线处理。默认安装为 CPU 版；NVIDIA GPU 机器需按 PyTorch 官方安装指南选择与驱动兼容的 CUDA 版 torch/torchvision，不直接照搬 CPU 锁文件。

## 实际处理流程

- 自动首帧选择：DeepLabV3 MobileNet V3 Large 定位人物，再使用 SAM 2.1 精细分割；长裙场景的提示框覆盖完整高度，避免仅选中头部或漏掉裙摆。根据模型置信度和人物区域覆盖率筛选结果，不要求用户提供 Matte。首帧提示模型有内部缩放，但逐帧 Alpha 推理保留原分辨率。
- 精细抠像：MatAnyone 2，十次首帧预热，逐帧时序记忆，不降采样处理。
- 高清合成：原片解码 PNG + 逐帧 Alpha PNG，FFmpeg `alphamerge`，VP9 Alpha / CRF 16 / 静音输出；不通过绿色预览片二次转码，不做锐化、超分或自动循环修复。
- 左侧为了兼容浏览器，会生成 CRF 16 的 H.264 预览。最终结果用的是原片 PNG，不使用左侧预览 MP4。
- 支持 MP4、MOV、WebM、MKV，最多 250 MB、60 秒、4K 像素量；当前以单人物、固定镜头为目标。多人物、复杂道具、透明面料可能误选，失败时明确报错，不退回伪抠像算法。
- 帧序列按检测到的平均帧率处理，适合固定帧率 AI 生成视频；可变帧率输入会按该帧率规范化，不保证保留原始 VFR 时间戳。

## 文件

`server/` FastAPI 后端；`web/` Vue 3 + TypeScript；`vendor/MatAnyone2/`、`vendor/SAM2/` 官方源码；`models/` 模型缓存；`data/jobs/<任务 UUID>/` 原片、原片预览、PNG 原帧和遮罩、结果、检查点与任务记录。数据不会自动删除，长视频的 PNG 母版会占用较多磁盘；确认不再需要后可人工删除对应任务目录。服务重启后，中断任务可点击恢复。

`models-manifest.json` 记录固定源码版本、官方模型来源和 SHA256；下载模型使用官方 GitHub assets API，安装器校验权重。源码、模型、venv、输出和构建目录不进入源码版本控制。
